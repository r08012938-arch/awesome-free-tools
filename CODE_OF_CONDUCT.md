# Code of Conduct

We want Awesome Free Tools to be a welcoming and respectful open-source project.

## Our expectations

- Be respectful and constructive.
- Help other contributors.
- Focus on improving the project.
- Don't harass, insult, or discriminate against others.
- Don't submit spam, scams, malware, or harmful content.

## Reporting issues

If you experience unacceptable behavior, open an issue privately with the project maintainer.

Thank you for helping keep this community friendly and useful.
