# Contributing to Awesome Free Tools

Thanks for helping improve Awesome Free Tools!

## How to contribute

1. Fork this repository.
2. Add one genuinely useful free tool.
3. Put it in the correct category.
4. Include the tool name, URL, and a short description.
5. Submit a Pull Request.

## Please don't submit

- Scam or malicious websites
- Pirated content
- Duplicate entries
- Misleading links
- Spam
- Tools that are not actually free

Keep contributions useful, accurate, and easy to understand.

Thanks for contributing! ❤️
